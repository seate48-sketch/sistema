SEATE — Restaurar backup

Gera o script que devolve todos os dados do Backup Geral a um banco de dados novo.

Quando usar

Somente se o banco de dados do sistema tiver sido perdido ou precisar ser recriado. Esta página não acessa o banco: ela apenas lê o arquivo de backup no seu computador e monta um script SQL para você rodar no Supabase.

Passo a passo

  1. No projeto Supabase novo (ou vazio), abra o SQL Editor e rode o script 00_criar_banco_completo.sql (estrutura do banco).
  2. Aqui, escolha o arquivo SEATE_Backup_Tecnico_AAAA-MM-DD.xlsx (baixado pelo botão Backup Geral) e clique em Gerar script de restauração.
  3. No SQL Editor, cole o conteúdo do arquivo restaurar_dados_….sql baixado e clique em Run. No fim aparece a contagem de linhas de cada tabela, para conferir com a tabela abaixo.
  4. No Supabase, em Authentication, crie de novo o usuário (e-mail e senha) do gestor.
  5. Se o endereço do projeto Supabase mudou, atualize a URL e a chave pública em config.js e publique o site.
